This project is about building a secure authentication system using Python's Flask framework and MongoDB as the database. The primary goal is to create a system where users can register, log-in, and Logout. Users will be able to sign up by providing details such as username, email, and password, with passwords being hashed using libraries like `werkzeug.security` before being stored in MongoDB to ensure security.
During registration this project have features like role-based access control, email verification during registration, and enhanced security measures such as rate limiting and CSRF protection.
During login, the system will verify user credentials by comparing the hashed passwords stored in the database. For session management, i can implement Flask sessions to handle authenticated user sessions.
MongoDB will serve as the backend database, storing user data such as usernames, emails, and hashed passwords, with interactions managed using PyMongo or Flask-PyMongo.
Overall, this project provides a hands-on opportunity to explore web security, database management, and backend development using Flask and MongoDB.
